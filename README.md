## 📖 About the Project

**Apex Construction Group** is a modern corporate landing page created as a portfolio and practice project.

The goal of this project was not simply to build a static webpage, but to practice designing and implementing a realistic company website with a professional structure, responsive layout, reusable styling, animations, accessibility considerations, and modern UI patterns.

The website represents a fictional construction company and presents its services, experience, projects, workflow, client feedback, and contact call-to-action.

## 🧱 Landing Page Sections

The page is structured around the following main sections:

### 1. Hero
The main introduction section that presents the company and creates the first visual impression.

### 2. Company Statistics
Highlights important company numbers and achievements.

### 3. About Us
Introduces the company, its experience, and its general identity.

### 4. Services
Presents the main construction and related services offered by the company.

### 5. Why Choose Apex
Explains the company's strengths and reasons clients should choose its services.

### 6. Featured Projects
Displays selected projects to showcase the company's portfolio.

### 7. From Planning to Completion
Illustrates the workflow and major stages of a construction project.

### 8. Testimonials
Shows feedback and experiences from fictional clients.

### 9. Call to Action
Encourages visitors to contact the company or start a project.

### 10. Footer
Contains the final navigation and company information.

## 📱 Responsive Design

The website was designed with responsiveness in mind and adapts to different screen sizes.

The layout is intended to work across:

- Desktop
- Laptop
- Tablet
- Mobile devices

Responsive techniques include flexible layouts, CSS Grid, Flexbox, media queries, and mobile navigation patterns.

---

## ♿ Accessibility

Accessibility was considered during development through practices such as:

- Semantic HTML elements
- Meaningful heading hierarchy
- `aria-label` and `aria-labelledby` where appropriate
- Improved structure for assistive technologies
- Clear content organization

## 🚀 Getting Started

Because this is a frontend project, no complicated installation is required.

### Clone the repository

```bash
git clone https://github.com/your-username/apex-construction-group.git
```

### Open the project

Navigate to the project directory:

```bash
cd apex-construction-group
```

Then open `index.html` in your browser.

For development, using **VS Code** with a local development server such as Live Server is recommended.
